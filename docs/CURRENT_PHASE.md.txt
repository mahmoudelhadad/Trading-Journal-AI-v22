## P2 Carry-Forward — recorded, NOT fixed

1. A genuine browser `QuotaExceededError` is a `DOMException` carrying
   `.name`, while the reporting helper classifies from `.kind`. Real quota
   exhaustion therefore maps to `errorKind: 'unknown'` and shows the generic
   blocking message instead of tailored storage-full wording. Not a v1
   blocker: the failure is visible, blocking, and no longer silent.
2. `%BASE_URL%favicon.svg` doubles the base path under the dev server only
   and still resolves; the production build output is correct.

Neither is a v1 blocker. Both are candidates for v1.1+.
