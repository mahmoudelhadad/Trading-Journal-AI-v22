# Current Phase

## Phase

Phase 28 — Finite Derived-Number Integrity

Status:

COMPLETE

---

## Objective

Guarantee that every derived numeric value is either a finite number or
null. Prevent malformed/non-finite raw operands and finite arithmetic
overflow from propagating NaN or Infinity through enrichment,
aggregation, running capital, equity, drawdown, newly computed Backtest
snapshots, or user-visible numeric output.

---

## Scope (as delivered)

- Added finite parsing and final-result checks without rewriting raw
  historical strings.
- Preserved valid finite calculations, valid negative inputs where
  previously accepted, and valid zero.
- Empty commission retains zero-fee behavior; invalid non-empty
  commission makes net P/L unavailable.
- Running capital never advances from unavailable/non-finite net P/L.
- Aggregate arithmetic overflow becomes null without clamping, skipping,
  JSON normalization, or fabricated zero.
- Equity, drawdown, and Backtest composition use whole-computation null
  results when a finite-only result cannot be produced.
- Backtest calculation failure is explicit and distinct from the saved
  result limit.
- Shared numeric formatters render unavailable/non-finite inputs as `—`.
- Dashboard, Strategy, Insights, Equity, Backtest, and Calendar local
  numeric producers and nullable consumers were hardened without
  secondary fallback analytics.

## Numeric Invariant

Every derived numeric value is finite or null.

- null means unavailable / not computable.
- 0 means valid numeric zero.
- NaN, +Infinity, and -Infinity are invalid derived state.
- Malformed, symbolic, non-finite, empty, or whitespace-only required
  numeric operands make the affected derived result unavailable.
- Finite arithmetic results are checked after calculation, including
  aggregate arithmetic.
- Unavailable state is not converted to zero merely to satisfy a UI,
  chart, comparison, type, or persistence contract.

## Whole-Computation Null Behavior

- `buildEquitySequence(...): EquityPoint[] | null`
- `computeDrawdown(...): DrawdownResult | null`
- `computeDrawdownFromTrades(...): DrawdownResult | null`
- `computeBacktestResult(...): BacktestResult | null`

EquityPoint remains finite-only. DrawdownResult fields remain finite-only.
`BacktestResult.equityPath` remains finite-only `number[]`. The AD-018
persisted shape and presence/absence legacy discriminator are unchanged.
No page rebuilds an alternative analysis when a shared calculation
returns null.

---

## Backtest Failure Contract

`calculation_unavailable` is distinct from `limit_reached`.

Exact inline message:

"Backtest could not be calculated because one or more required numeric
calculations were unavailable."

On `calculation_unavailable`, no Backtest result is appended, persisted,
selected, partially saved, or fabricated through fallback recomputation.
