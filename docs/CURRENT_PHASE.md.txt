# Current Phase

## Phase

Phase 26 — Immutable Backtest Equity Snapshots

Status:

COMPLETE

---

## Objective

Make every newly saved BacktestResult an immutable analytical snapshot
for the equity outputs that were previously rebuilt from mutable
journal trades: the Equity Curve, Ending Equity, and comparison return
series. Preserve old saved results without fabricating a historical
path, and identify their reconstructed current-data outputs clearly.

---

## Scope (as delivered)

New results persist one additive field:

`equityPath?: number[]`

It contains raw, unrounded cumulative equity after each matched trade,
in matched order. `startingCapital` is the implicit point zero; `[]`
means zero matched trades. Presence of the property is the sole frozen-
result discriminator. Absence — not null and not an empty array — means
legacy.

`computeBacktestResult()` captures the path from the equity sequence it
already computes for drawdown. The result page uses it for the Equity
Curve and Ending Equity. Comparison uses it for each result's
percentage-return series. Current journal trades remain relevant to new
results only for existing traceability such as unresolved matched IDs,
not as the source of these frozen analytical outputs.

Legacy results are not migrated, backfilled, or rewritten. Their
original paths were never stored and cannot be authenticated or
recovered. They retain the existing current-trade reconstruction, with
a prominent notice covering the Equity Curve and Ending Equity; each
legacy side in a comparison receives its own notice. Stored legacy
metrics remain unchanged.

AD-018 records the architecture change and supersedes AD-015 clause 2
only. AD-015 clauses 1 and 3 remain approved. AD-015 is preserved as
historical record, and AD-014 is untouched.

## Adjacent Finding

`Avg Risk ($)` rendered as `-$NaN` on the freshly created result and as
`—` after reload. JSON serialisation converts non-finite numeric values
such as NaN to null. The value comes from the pre-existing `_rv` / Core
Analytics path, untouched by Phase 26; it is unrelated to `equityPath`
and is not a Phase 26 regression. It was recorded, not fixed. The
equity path itself contained finite values and its endpoint reconciled
with stored Net P&L.
